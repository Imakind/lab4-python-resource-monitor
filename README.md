## Запуск

Требуются Python 3.12+ и psutil. Команды Windows:

```powershell
python -m venv venv
.\venv\Scripts\python.exe -m pip install -r requirements.txt
.\venv\Scripts\python.exe inventory.py
.\venv\Scripts\python.exe monitor.py
.\venv\Scripts\python.exe check_results.py
```

На Linux/macOS используется `venv/bin/python`.

- `inventory.py` собирает характеристики, IPv4/маску/MAC и рекомендации, сохраняет локальный JSON.
- `monitor.py` сохраняет CSV, проверяет пороги, выводит среднее, максимум и минимум.
- `experiment.py` запускает монитор и отдельные процессы нагрузки; предел памяти — минимум из 512 МиБ, половины RAM и четверти доступной памяти. Через 5 секунд после запуска монитора включается нагрузка; после замеров созданные процессы завершаются.
- `check_results.py` проверяет правила анализа, пороги, статистику и сетевую функцию на обозначенных тестовых данных. Он не собирает и не публикует сетевые параметры компьютера.

Дополнительный опыт: `python experiment.py`. Вновь собранные локальные результаты могут содержать личные данные; `.gitignore` исключает их из обычного `git add`.

## Полученные результаты

| Метрика | Среднее под нагрузкой | Максимум | Минимум |
| --- | --- | --- | --- |
| CPU, % | 21.423 | 56.9 | 11.9 |
| RAM, % | 85.897 | 87.3 | 84.1 |
| Занято на диске, % | 81.6 | 81.6 | 81.6 |
| Число процессов | 353.533 | 356 | 350 |

RAM превысила порог уже до нагрузки. В выполненном эксперименте выделено **512 МиБ вместо 2 ГиБ**, чтобы сохранить запас памяти для ОС. Один поток CPU получил 24.83 секунды процессорного времени. Это результаты конкретного опыта, а не гарантированные показатели любого компьютера.

## Что обезличено и что исключено

Публичная версия создана отдельно от исходных материалов. В паспорте скрыты имя компьютера, сетевые адреса, маски, MAC, имена интерфейсов и время. В CSV абсолютное время заменено номером замера и относительной секундой; измеренные значения сохранены. Из отчёта удалены идентификаторы и небезопасные изображения.

Опубликованы **два из восьми** оригинальных скриншотов: рекомендации и проверки. Они просмотрены и скопированы без изменения пикселей. Скриншот проверок относится к исходной выполненной работе; публичный проверочный скрипт не повторяет приватную проверку `ipconfig`.

Не опубликованы исходные Word/PDF, исходный архив, полные журналы `ipconfig`, сетевые скриншоты, список пользовательских приложений, абсолютные временные отметки и PID процессов. Эти файлы не входят в историю Git.
